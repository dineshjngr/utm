UTMCraft vs. Google’s Official Campaign URL Builder

For over a decade, digital marketers relied on Google's standard DevSite Campaign URL Builder. While functional for single links, it was built in the Universal Analytics era and lacks the intelligence required for modern Google Analytics 4 (GA4) attribution pipelines. Below is a feature-by-feature comparison:

💡 Why Universal Analytics Practices Break GA4

Universal Analytics (UA) was forgiving of mixed casing and non-standard mediums like medium=social-media or medium=email-blast. GA4 enforces rigid regular expression rules: if your medium does not strictly match its regex dictionary, your entire campaign session is assigned to (Unassigned), permanently breaking attribution models.

Google Analytics 4 Campaign Parameters: Core & Additional Parameters

GA4 supports 9 manual campaign parameters: six commonly used/core parameters plus three additional GA4 parameters. Some newer parameters currently have reporting limitations. Google documents the traditional manual parameters plus utm_source_platform, utm_creative_format, and utm_marketing_tactic; Google also separately documents and recommends utm_id. Google notes that utm_creative_format and utm_marketing_tactic are not currently reported in GA4 properties.

Below are the six core parameters commonly used in URL builders, followed by GA4's three additional campaign parameters:

Parameter Classification Required GA4 Dimension Primary Use Case & Reporting Status
utm_source Core Parameter Yes Session source / First user source Identifies the referrer or platform driving the user. Reported in all standard reports.
utm_medium Core Parameter Recommended Session medium / First user medium Determines the marketing channel grouping in GA4. Required for channel grouping.
utm_campaign Core Parameter Recommended Session campaign / First user campaign Names the specific product initiative, promotion, or theme. Reported in all standard reports.
utm_id Core Parameter Recommended Campaign ID / Session campaign ID Recommended by Google to match and upload offline cost data via GA4 Data Import.
utm_term Core Parameter Optional Session manual ad term Tracks paid search keywords or specific audience segment targeting.
utm_content Core Parameter Optional Session manual ad content Differentiates creative variants, banner sizes, or copy variations for A/B testing.
utm_source_platform Additional GA4 Parameter Optional Manual source platform Identifies the sending platform interface (e.g. Search Ads 360, Google Ads). Available in reports & BigQuery.
utm_creative_format Additional GA4 Parameter Optional Manual creative format Identifies creative type (video, carousel). Reporting limitation: Google notes this is not currently reported in GA4 properties.
utm_marketing_tactic Additional GA4 Parameter Optional Manual marketing tactic Targeting strategy (prospecting, remarketing). Reporting limitation: Google notes this is not currently reported in GA4 properties.

How to Build & Deploy Campaign URLs: A 5-Step Process

  1. Identify the Clean Destination URL: Ensure your target page is live, resolves with an HTTPS protocol, and does not trigger an internal redirect that strips query strings.
  2. Apply Standardized Source & Medium: Always consult GA4 Default Channel Grouping rules. For paid social ads, use medium=paid_social; for Google Ads Search, use medium=cpc.
  3. Name Your Campaign with Strict Conventions: Use lowercase text and hyphens to separate words. Example: brand-awareness-na-2025 instead of Brand Awareness (NA) 2025.
  4. Differentiate Creatives with utm_content: If testing multiple images or ad copy angles in the same ad group, use utm_content=static_infographic vs utm_content=short_video.
  5. Verify in GA4 Realtime Reports: Before launching high-budget campaigns, click your tagged URL in an incognito window and check Google Analytics 4 → Reports → Realtime to ensure your source and medium appear correctly under Session Source / Medium.

Frequently Asked Questions

How is this Campaign URL Builder different from Google's official DevSite tool?

Core URL generation and auditing run in your browser without storing campaign inputs in a UTMCraft account or database. If you choose the optional shortener, the generated URL is sent to a public shortening provider. The tool also adds GA4 channel scoring, QR export, bulk generation, and lowercase sanitization.

Which parameters are mandatory in Google Analytics 4?

For accurate attribution, your Destination URL and utm_source are strictly mandatory. However, without utm_medium, GA4 cannot classify your session into a Default Channel Group, causing the traffic to default to (Unassigned).

Does utm_id replace utm_campaign?

No. utm_id complements utm_campaign by providing an alphanumeric identifier that matches campaign IDs across ad platforms (such as Google Ads or Meta Ads Manager). It is especially valuable when importing external cost or revenue data into GA4.

Why should I never use UTM parameters on internal website links?

Campaign UTMs should not be used on internal navigation. GA4 does not start a new session when new campaign values appear, but it can associate those values with mid-session events and distort event-scoped attribution. Use internal-promotion events instead.

What happens if my destination page redirects (e.g. HTTP to HTTPS or non-www to www)?

Many web servers strip query parameters during 301 or 302 redirects unless specifically configured with a query string pass-through (QSA). Always ensure your destination URL matches the final canonical URL to prevent parameter loss.
