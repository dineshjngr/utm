The 7 Costliest UTM Mistakes Detected by This Checker

A typo or missing value can affect campaign reporting. The checker flags several URL issues that are useful to review before launch:

Error Type Example Mistake Why It Corrupts GA4 Analytics
Mixed Casing utm_source=Facebook GA4 default channel definitions are not case-sensitive. Differently capitalized manual source or campaign values can appear separately in reports, so consistent naming can make comparisons easier.
Unencoded Spaces utm_campaign=summer sale Spaces become %20 or +, which can break parameter parsers and create messy regex groupings.
Duplicate '?' Delimiters https://site.com/?p=1?utm_source=... A URL may only have ONE question mark. The second ? is treated as literal parameter text, destroying all following UTMs.
Hashtag Placement Error https://site.com/#intro?utm_source=... Text after # is a URL fragment, not part of the query string sent in the HTTP request. Standard UTM collection may not read campaign values placed there; custom client-side handling can vary.
Missing Campaign Medium utm_source=google (no medium) Missing campaign fields can limit classification. GA4 may use other available campaign or referrer information when processing the session.
Internal Website UTMs Home page linking to /pricing?utm_source=home Internal campaign parameters can affect campaign data collected on later events. Use event parameters for on-site promotions and verify reporting for your implementation.
Redirect Stripping http://site.com?utm_... → https://site.com A redirect may preserve or drop query parameters depending on its rule and server configuration. Check the redirect chain and final URL. Apache's QSA is specific to Apache mod_rewrite.

Pre-Launch Campaign Link QA Checklist

  1. Check Canonical Protocol: Does the link start with https://? Does it match your domain's exact canonical formatting (www vs non-www)?
  2. Check Naming Consistency: Do source and campaign values follow your documented naming convention? Lowercase is a useful convention for consistency.
  3. Review Channel Definitions: Compare source, medium, and other available campaign information with Google's current definitions. Channel assignment depends on the data GA4 receives.
  4. Test in Incognito Mode: Paste the full link into a private browser tab and verify that the page loads with a 200 HTTP response and that parameters remain in the address bar.
  5. Check GA4 Realtime View: Visit Google Analytics 4 → Reports → Realtime and confirm your test visit shows the expected Session Source / Medium.

Frequently Asked Questions

Can this checker audit URLs created by other UTM tools?

Yes. The UTM Checker inspects the URL text generated by any tool, spreadsheet, ad platform, or CRM. It checks syntax, selected parameter presence, casing consistency, spaces, and a limited set of source/medium patterns; it does not verify compliance against every current Google Analytics rule.

What does an audit score of 100% mean?

A score of 100 means the URL passed the checks used for this score, such as syntax and selected parameter and naming checks. It does not mean the link was tested through live redirects or that GA4 will assign a particular channel.

Can I inspect URLs that have non-UTM query parameters?

Yes. The checker separates standard UTM parameters from platform tracking tokens (like gclid, fbclid, or custom parameters like ref or affiliate_id) and displays them in distinct diagnostic cards.
