How to Find & Check UTM Campaign Traffic in GA4

A step-by-step visual roadmap to locate your campaign clicks, custom UTMs, and conversion metrics inside Google Analytics 4.

Method 1 • Quick Test

1. Realtime Report (Instant 10-Second Test)

Before launching ad spend, click your UTM link and verify it appears immediately in GA4.

GA4 › Reports › Realtime
  • Look for the "Users by First user source / medium" card.
  • Verify your utm_source and utm_medium appear within 10 to 30 seconds.
  • Scroll down to "Event count by Event name" to verify page_view and session_start fired.
Pro Tip: Open your tagged link in an Incognito window to trigger a fresh session.
Method 2 • Core Reporting

2. Traffic Acquisition Report (Sessions & Medium)

The primary standard report for analyzing which marketing channels and campaigns drove traffic.

GA4 › Reports › Acquisition › Traffic acquisition
  • Click the primary dimension dropdown (defaults to Session default channel group).
  • Switch to "Session source / medium" to see exact pairings (e.g. facebook / paid_social, google / cpc).
  • Or switch to "Session campaign" to evaluate each utm_campaign initiative.
  • Click the blue "+" icon to add a secondary dimension: search for "Session manual ad content" to view utm_content variations.
Note: Standard reports in GA4 may take 24–48 hours to fully process historical batch data.
Method 3 • First-Touch Attribution

3. User Acquisition Report (How New Users Found You)

Reveals which campaigns originally introduced net-new visitors to your website or product.

GA4 › Reports › Acquisition › User acquisition
  • Select "First user source / medium" as primary dimension.
  • Evaluate metrics: New users, Engaged sessions, and Engagement rate.
  • Compare against Traffic acquisition to spot the difference between new user acquisition and return traffic.
Key Insight: Shows the top-of-funnel campaign that sparked first contact.
Method 4 • Advanced Analysis

4. Free-Form Explorations (Custom Multichannel Pivot)

Create custom pivot tables combining source, medium, campaign, content, and revenue.

GA4 › Explore › Free-form exploration
  • Import Dimensions: Session source / medium, Session campaign, Session manual ad content, Landing page + query string.
  • Import Metrics: Sessions, Active users, Key events (Conversions), Total revenue.
  • Drag dimensions into Rows and metrics into Values for full conversion attribution!
Power Feature: Filter rows where Session campaign is not (not set).

Official GA4 Default Channel Grouping Rules Matrix

In Google Analytics 4, sessions are assigned to channel groups based on a strict hierarchy evaluated from top to bottom. If a session fails rule #1, it falls to rule #2, and so forth. If no rule matches, it lands in (Unassigned).

GA4 Channel Group Required Source Required Medium (Regex) Recommended Value
Paid Search Matches Google Ads or ad network ^(.*cp.*|ppc|paid.*)$ source=google&medium=cpc
Paid Social Matches social network list (meta, linkedin, etc.) ^(.*cp.*|ppc|paid.*)$ source=facebook&medium=paid_social
Organic Social Matches social network list ^(social|social-network|social-media)$ or exact social source source=linkedin&medium=social
Email Any source ^(.*email.*)$ source=newsletter&medium=email
Display Any source ^(display|banner|expandable)$ source=google&medium=display
Paid Video Matches video network (youtube, vimeo, tiktok) ^(.*cp.*|ppc|paid.*)$ source=youtube&medium=cpc
Organic Video Matches video network ^(.*video.*)$ source=youtube&medium=video
Affiliates Any source ^(affiliate|affiliates)$ source=partner_name&medium=affiliate
Referral Any website domain ^(referral|app)$ source=partner.com&medium=referral

How to Diagnose & Fix (Unassigned) Traffic in GA4

Seeing high percentages of (Unassigned) in your Traffic Acquisition reports is the #1 symptom of broken UTM taxonomy. Follow this 4-step diagnostic protocol:

  1. Navigate to Reports → Acquisition → Traffic Acquisition: In the primary dimension dropdown, change Default channel group to Session source / medium.
  2. Filter by (Unassigned): Add a secondary dimension: Session manual ad content or search for rows where the channel shows as (Unassigned). You will immediately pinpoint the exact source/medium combinations causing the failure.
  3. Identify Regex Violations: Look for uppercase characters (e.g. Cpc instead of cpc), underscores where hyphens are expected, or custom invented mediums like medium=promo or medium=pdf.
  4. Update Channel Grouping Definitions or Re-tag: If historical traffic cannot be changed, you can edit your GA4 property's Custom Channel Grouping under Admin → Data display → Channel groups to map your custom mediums to standard categories.

⚠️ Beware of Ad Blockers Stripping GCLID

When Google Ads auto-tagging (gclid) is stripped by privacy browsers or Safari ITP, Google Analytics falls back on manual UTM tags. If you have not configured manual UTM parameters or a Final URL Suffix in Google Ads, the click has neither gclid nor UTMs, forcing it into Direct or Unassigned.

Frequently Asked Questions

What is the difference between Session Source and First User Source in GA4?

First user source/medium attributes all future user activity to the very first campaign that brought that individual user to your website. Session source/medium attributes only the current session, allowing you to track multi-touch return visits and seasonal promotions.

Can I use uppercase letters in GA4 UTM tags?

No. Never use uppercase letters. Google Analytics 4 treats utm_source=Google and utm_source=google as two completely distinct sources. Furthermore, GA4's default channel regex matching often expects lowercase strings, causing uppercase values to fall into (Unassigned).

Does GA4 still support utm_term and utm_content?

Yes. In GA4, utm_term maps to the Session manual ad term dimension, and utm_content maps to the Session manual ad content dimension. Both dimensions can be viewed as secondary dimensions in standard reports or added to custom Free-form Explorations.
