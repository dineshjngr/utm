5 QR Code Tracking Mistakes to Avoid in Print & Offline Campaigns

Review 5 QR code tracking mistakes that can affect campaign reporting, including scanning issues and redirect behavior, with steps for checking attribution.

Already have a QR campaign link or print proof? Use this diagnostic checklist to find scanning, redirect, and tagging problems before distribution. For the initial setup, follow the QR code UTM tracking tutorial.

Why Printed QR Codes Are Irreversible

A printed QR code encodes a fixed URL. If that URL points to a redirect you control, you may be able to update its destination. When diagnosing poor reporting, scan the printed proof, inspect every redirect hop, and check which campaign values reach the landing page.

The 5 Most Damaging QR Code Tracking Mistakes

1. Encoding Plain URLs Without Campaign Parameters

Printing https://brand.com/booth without campaign parameters can make it harder to identify QR-driven visits in GA4, particularly when no usable referrer information is available.

2. Printing 200-Character Static URLs (Unscannable Modules)

Long URLs produce denser QR matrices that may be harder to scan at a given print size. If scans fail, try the actual print size on the intended material and lighting; compare with a shorter destination URL that you control.

3. Using Static QR Codes for Expensive Print Runs

If the printed code embeds the final landing URL directly, that encoded URL cannot be changed after printing. A redirect on a domain you control can provide a changeable destination, but test that it preserves the query string.

4. Violating Contrast and Quiet Zone Requirements

If scanning is unreliable, check contrast, damage near the code edges, and whether the quiet zone is clear. Test with the printed proof on more than one device.

5. Using a QR Medium Without Checking Channel Reporting

Values such as qr, print, or event describe your campaign convention, but a medium alone does not determine the GA4 default channel. If a channel looks unexpected, inspect the collected source and medium against Google's current channel definitions; use a custom channel group if your team needs a separate offline category.

Pre-Print QR Verification Checklist

  • Print a 100% scale proof on physical paper before authorizing press runs.
  • Scan the printed proof with both an iOS Camera app and an Android Google Lens.
  • Confirm all UTM parameters persist in the browser address bar after page load.

Frequently Asked Questions

What if the code scans but GA4 does not show the campaign?

Compare the scanned URL, each redirect destination, and the final page URL. If parameters survive, test whether the analytics tag receives them and inspect the collected source/medium values in GA4.

What utm_medium should I use for QR codes?

Choose and document a medium such as print or event that identifies the placement for your team. Review the resulting GA4 source/medium values and, if needed, define an offline category in a custom channel group.
