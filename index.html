UTM builder FAQs

What is a UTM URL?

A UTM URL is a destination link with campaign parameters that identify where a visit came from and which campaign drove it.

Which UTM parameters are required?

Use utm_source, utm_medium, and utm_campaign for dependable reporting. Term, content, and campaign ID are optional.

GA4 taxonomy FAQs

Why does GA4 channel grouping matter?

GA4 uses source and medium values to classify traffic. Consistent values reduce unassigned traffic and fragmented reports.

Should UTM values use lowercase?

Yes. Analytics can treat differently capitalized values as separate entries, so lowercase naming keeps reports cleaner.
